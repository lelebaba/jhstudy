📌 题目展示与解析

📄 题目原文

学习以下材料，回答(1)~(4)题。

线粒体基因编码蛋白质双重翻译模式的新发现

真核细胞生命活动所需能量约95%来自线粒体。线粒体正常运转需要上千种蛋白质，但线粒体基因组DNA (mtDNA)只编码13种蛋白，其中包括线粒体内膜上的细胞色素b (Cytb)。Cytb由380个氨基酸组成，是电子传递链复合体Ⅲ的一个亚基，参与电子传递，驱动ATP合成。

线粒体遗传密码与核遗传密码(标准密码子)相似但不完全相同。如标准异亮氨酸密码子AUA在线粒体中编码甲硫氨酸，精氨酸密码子AGA和AGG在线粒体中则为终止密码子，而终止密码子UGA在线粒体中编码色氨酸。

以往认为，线粒体中的CYTB基因只编码Cytb。我国科研人员发现CYTB基因还能编码由187个氨基酸组成的蛋白质C-187，且C-187是在细胞质基质中的核糖体上按照标准密码子翻译出来的。C-187合成后，再由特定的序列引导其返回线粒体基质中。

研究发现，C-187能与线粒体内膜上的SL蛋白结合。SL蛋白由核基因编码，可跨膜转运磷酸盐。若C-187合成障碍则会导致细胞内ATP含量下降，而SL基因过表达则能够恢复细胞内ATP水平，二者在能量代谢中共同发挥作用。

该研究不仅改写了"线粒体基因组编码13个蛋白"的论断，提出的线粒体双重翻译模式也为研究能量代谢调控提供了新视角。

第(4)题

答案：

Cytb作为电子传递链复合体Ⅲ的亚基，参与电子传递过程，建立线粒体内膜两侧的质子梯度，为ATP合成提供能量（动力）；C-187与SL蛋白结合，SL蛋白将磷酸盐（Pi）转运进入线粒体，为ATP合成提供底物（原料）。两者分别从"能量供应"和"原料供应"两个维度协同配合，共同驱动ATP的合成。

解析：

  • Cytb的角色：像"水电站"——通过电子传递建立质子梯度，产生驱动ATP合成的动力（质子动力势）
  • C-187/SL的角色：像"原材料运输队"——把磷酸盐（Pi）运进线粒体，ATP的合成需要ADP + Pi
  • 缺一不可：只有动力没有原料（Pi）不行，只有原料没有动力也不行
🍳 生活类比

做一道菜（合成ATP）：

  • Cytb = 炉灶（提供火/能量）——没有火，菜做不熟
  • C-187/SL = 食材配送员（提供原料）——没有食材，火再大也没用
  • 两者协同配合，才能做出一道菜（合成ATP）

🔬 ① 线粒体与有氧呼吸

基础知识

线粒体——细胞的"发电厂"

💡 通俗比喻

想象一下：你的手机需要电池才能工作，而你的身体里每个细胞都有自己的"充电电池"——线粒体就是给这些电池充电的"发电厂"。

你吃进去的食物（比如米饭、肉）就是"煤炭"，线粒体这个发电厂把"煤炭"烧掉，产生能量，给细胞的一切活动供电。

线粒体的结构

线粒体有两层膜：

  • 外膜：最外面的一层，比较通透
  • 内膜：向里折叠形成嵴（cristae），增大了表面积——就像把一张纸折成手风琴状，能放更多"机器"（电子传递链复合体）
  • 膜间隙：内外膜之间的空间
  • 基质：最里面的空间，含有线粒体自己的DNA（mtDNA）和核糖体

有氧呼吸三阶段

有氧呼吸分为三个阶段，好比"发电"的三个步骤：

阶段发生场所核心变化产物
① 糖酵解 细胞质基质 葡萄糖分解为丙酮酸 少量ATP + [H]（NADH）
② 柠檬酸循环（三羧酸循环） 线粒体基质 丙酮酸进一步分解 少量ATP + [H]（NADH、FADH₂）+ CO₂
③ 氧化磷酸化（电子传递链） 线粒体内膜 [H]中的电子传递，最终交给O₂ 大量ATP + H₂O

🔑 与本题相关：

第(1)题考的就是"线粒体是有氧呼吸的主要场所"，以及前两阶段产生的[H]在第三阶段与O₂结合生成H₂O。

🔬 细胞呼吸全过程

基础知识
🔥 生活类比："烧煤发电"的全过程

把细胞呼吸想象成火力发电厂烧煤发电的过程：

  • 糖酵解 = 把大块煤敲碎成小块（葡萄糖→丙酮酸）
  • 柠檬酸循环 = 把小块煤进一步粉碎成煤粉（丙酮酸→CO₂+[H]）
  • 氧化磷酸化 = 把煤粉送进炉膛燃烧，推动涡轮发电（[H]→电子传递→ATP）

总反应式

C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O + 能量（约30-32 ATP）

这个反应式告诉我们：细胞呼吸就是"吃进去葡萄糖，吸入氧气，呼出二氧化碳，产生水和能量"。

什么是[H]？

题目中提到的"[H]"其实是一个简写，指的是还原型辅酶：

  • NADH（烟酰胺腺嘌呤二核苷酸，还原型）
  • FADH₂（黄素腺嘌呤二核苷酸，还原型）

它们就像"电子快递员"——把从食物中提取的电子运送到电子传递链。

⚡ ② 电子传递链 & ATP合成

核心知识
💡 通俗比喻"接力赛"

电子传递链就像一场接力赛：

  • 运动员 = 电子传递链上的蛋白质复合体（Ⅰ、Ⅱ、Ⅲ、Ⅳ）
  • 接力棒 = 电子
  • 终点线 = 氧气（O₂）——最终接收电子
  • 每传一次棒，就"释放"一点能量，用来把H⁺泵到膜间隙——就像在给"水坝"蓄水

电子传递链（位于线粒体内膜）

电子传递链由四个蛋白质复合体（Ⅰ、Ⅱ、Ⅲ、Ⅳ）和两个移动电子载体（CoQ、Cytc）组成。其中复合体Ⅲ就是本题中Cytb所在的位置。

流程：

NADH/FADH₂ → 复合体Ⅰ/Ⅱ → CoQ → 复合体Ⅲ（含Cytb） → Cytc → 复合体Ⅳ → O₂

每一步电子传递，都伴随着H⁺从线粒体基质泵到膜间隙，建立起质子梯度（H⁺浓度差）。

ATP合成酶——"水力发电机"

💡 通俗比喻

质子梯度就像一个水坝——膜间隙的H⁺多（水位高），基质的H⁺少（水位低）。

H⁺通过ATP合成酶流回基质时，就像水从高处流下推动水轮机——ATP合成酶就利用这股"水流"的能量，把ADP和Pi合成为ATP。

🔑 与本题相关：

第(4)题中，Cytb是复合体Ⅲ的一个亚基，负责电子传递和质子泵出，为ATP合成提供"动力"。

⚡ 化学渗透假说

基础知识
💡 通俗比喻："水坝发电"

化学渗透假说可以这样理解：

  1. 建坝蓄水：电子传递链把H⁺从基质泵到膜间隙 → 就像用水泵把水抽到高处的水库
  2. 水位差形成：膜间隙H⁺浓度高（高水位），基质H⁺浓度低（低水位）→ 形成质子动力势
  3. 开闸放水：H⁺通过ATP合成酶流回基质 → 就像水从高处流下推动水轮机
  4. 发电：ATP合成酶利用这股力量把ADP+Pi合成ATP → 就像水轮机带动发电机发电

这个理论由英国科学家彼得·米切尔提出，并因此获得1978年诺贝尔化学奖。

🧬 ③ 遗传密码的奥秘

核心知识
💡 通俗比喻"字典"

遗传密码就像一本翻译字典：

  • DNA（基因） = 一本用"密码子"写成的菜谱
  • mRNA = 菜谱的复印件
  • 核糖体 = 厨师（按照菜谱做菜）
  • 氨基酸 = 食材
  • 蛋白质 = 做好的菜

每个"密码子"（3个核苷酸一组）对应一种氨基酸——就像"番茄炒蛋"这个菜名对应番茄和鸡蛋这两种食材。

中心法则

DNA →（转录）→ mRNA →（翻译）→ 蛋白质
  • 转录：以DNA为模板合成mRNA（在细胞核/线粒体中进行）
  • 翻译：以mRNA为模板合成蛋白质（在核糖体上进行）

标准密码子 vs 线粒体密码子

本题最核心的考点之一：线粒体有自己的"方言"！

密码子标准密码子（核）线粒体密码子
AUA异亮氨酸甲硫氨酸
AGA / AGG精氨酸终止密码子
UGA终止密码子色氨酸
💡 通俗理解

想象一下：标准密码子是"普通话"，线粒体密码子是"方言"。

同样一个词，在普通话和方言里意思不一样：

  • UGA在普通话里是"停下"（终止），在方言里是"做菜"（色氨酸）
  • AUA在普通话里是"番茄"（异亮氨酸），在方言里是"鸡蛋"（甲硫氨酸）

所以，同一个mRNA，用普通话翻译和用方言翻译，会得到不同的蛋白质！

🔑 与本题相关：

这就是"双重翻译模型"的核心机制！CYTB-mRNA在线粒体核糖体上用"方言"翻译 → Cytb（380aa）；在细胞质核糖体上用"普通话"翻译 → C-187（187aa）。

🧬 转录与翻译

基础知识
💡 通俗比喻"做菜"

转录 = 把菜谱从珍藏本（DNA）复印到便签纸（mRNA）上——珍藏本不能带进厨房，但便签纸可以

翻译 = 厨师（核糖体）照着便签纸（mRNA）上的菜谱，从冰箱（细胞质）拿食材（氨基酸），做出一道菜（蛋白质）

转录（Transcription）

  • 场所：细胞核（核基因）或线粒体基质（线粒体基因）
  • 模板：DNA的一条链
  • 酶：RNA聚合酶
  • 产物：mRNA（信使RNA）

翻译（Translation）

  • 场所：核糖体（细胞质核糖体 或 线粒体核糖体）
  • 模板：mRNA
  • "搬运工"：tRNA（转运RNA）——每个tRNA携带一种氨基酸，一端有反密码子，与mRNA上的密码子配对
  • 产物：多肽链（蛋白质）

🧬 密码子对照表

基础知识

密码子是mRNA上每3个相邻的核苷酸组成的一组，对应一种氨基酸（或终止信号）。

4种碱基（A、U、G、C）× 3个一组 = 4³ = 64种密码子。

而常见氨基酸只有20种，所以多种密码子可以对应同一种氨基酸——这叫做"密码子的简并性"。

本题中关键的密码子差异

密码子标准密码子（核基因组）线粒体密码子
AUA异亮氨酸 (Ile)甲硫氨酸 (Met)
AGA精氨酸 (Arg)终止密码子 (Stop)
AGG精氨酸 (Arg)终止密码子 (Stop)
UGA终止密码子 (Stop)色氨酸 (Trp)

⚠️ 重要提示：

正因为线粒体密码子和标准密码子不同，同一个CYTB-mRNA在两种翻译系统中会得到两种不同的蛋白质：

  • 在线粒体核糖体翻译：遇到UGA读作"色氨酸"→ 得到380个氨基酸的Cytb
  • 在细胞质核糖体翻译：遇到UGA读作"终止"→ 翻译提前终止 → 得到187个氨基酸的C-187

🔄 ④ 双重翻译模型

本题核心

🎯 什么是"双重翻译"？

一个基因（CYTB）的mRNA，在两个不同的地方，用两套不同的密码子规则，翻译出两种不同的蛋白质。

💡 通俗比喻"双语说明书"

想象一份双语说明书（就是CYTB-mRNA）：

  • 用中文读（线粒体密码子）→ 得到一份完整的说明书（Cytb，380页）
  • 用英文读（标准密码子）→ 只读到一半就结束了（C-187，187页）

为什么？因为在中文里"UGA"是"继续"（色氨酸），在英文里"UGA"是"到此为止"（终止密码子）！

为什么C-187在线粒体核糖体翻译不出来？

在线粒体核糖体中，mRNA上的密码子按线粒体规则翻译。当遇到UGA时，线粒体读作"色氨酸"，所以翻译不会终止，一直翻译到380个氨基酸的Cytb。

而在细胞质核糖体中，UGA被读作"终止密码子"，所以翻译提前终止，只得到187个氨基酸的C-187。

🤝 ⑤ C-187与SL蛋白的协作

进阶知识
💡 通俗比喻"外卖配送"

把线粒体想象成一个厨房，ATP是一道菜：

  • Cytb = 厨师（负责炒菜——提供能量）
  • 磷酸盐（Pi） = 食材（做ATP的原料之一）
  • SL蛋白 = 送菜窗口（把食材从外面送进厨房）
  • C-187 = 服务员（站在送菜窗口旁边，确保食材顺利送达）

C-187和SL蛋白结合，就像服务员和送菜窗口配合——确保食材（磷酸盐）源源不断地送进厨房，厨师（Cytb）才能一直做菜（合成ATP）。

关键信息梳理

蛋白质基因位置翻译位置功能
Cytb mtDNA（线粒体基因组） 线粒体核糖体 复合体Ⅲ亚基，电子传递，建立质子梯度
C-187 mtDNA（线粒体基因组） 细胞质核糖体（按标准密码子） 与SL蛋白结合，促进磷酸盐转运
SL蛋白 细胞核基因组 细胞质核糖体 跨膜转运磷酸盐（Pi）进线粒体

🔑 第(4)题完整答案：

Cytb作为电子传递链复合体Ⅲ的亚基，参与电子传递，建立起线粒体内膜两侧的质子梯度，为ATP合成提供能量（质子动力势）。

C-187与线粒体内膜上的SL蛋白结合，SL蛋白负责将磷酸盐（Pi）转运进入线粒体基质，为ATP合成提供底物（Pi）。

两者分别从能量供应和原料供应两个维度协同配合，缺一不可，共同驱动ATP的合成。

实验证据

  • C-187合成障碍 → ATP含量下降：说明没有C-187，磷酸盐运不进来，ATP合成缺原料
  • SL基因过表达 → ATP水平恢复：说明即使C-187出问题，多装几个"送菜窗口"（SL蛋白）也能弥补一些
  • 这证明了C-187和SL蛋白在能量代谢中共同发挥作用

线粒体基因COX2的新发现

线粒体是真核细胞进行有氧呼吸的主要场所。线粒体基因组（mtDNA）编码的蛋白质中，细胞色素c氧化酶（Complex Ⅳ）的亚基Ⅱ（COX2）是电子传递链的重要组分。

已知线粒体遗传密码与标准遗传密码存在差异：在线粒体中，AUA编码甲硫氨酸，AGA和AGG为终止密码子，UGA编码色氨酸。

以往认为，线粒体COX2基因只编码COX2蛋白（由259个氨基酸组成）。近期研究发现，该基因还能编码一种由148个氨基酸组成的蛋白质——MOTS-k。MOTS-k在细胞质核糖体上按照标准密码子翻译，合成后定位于线粒体基质，参与调控细胞代谢。

进一步研究发现，MOTS-k能够与线粒体内膜上的转运蛋白MTM结合，MTM负责将丙酮酸转运进入线粒体基质。若MOTS-k合成受阻，丙酮酸进入线粒体的效率降低，导致细胞ATP合成减少。

(3) 阐述COX2和MOTS-k在ATP合成过程中的协调配合。

✅ 参考答案与解析

第(1)题

答案：二（或"二"）；O₂

解析：有氧呼吸第二阶段（柠檬酸循环）发生在线粒体基质中，产生的[H]（NADH、FADH₂）在第三阶段通过电子传递链将电子传递给O₂，生成H₂O。

第(2)题

答案：A、C

解析：

  • A ✓：抑制线粒体基因转录 → MOTS-k下降 → 说明MOTS-k合成依赖mtDNA转录
  • B ✗：抑制细胞质核糖体翻译 → MOTS-k下降 → 只能证明MOTS-k在细胞质翻译，不能证明基因来源
  • C ✓：mtDNA缺失细胞中检测不到MOTS-k → 直接证明MOTS-k由mtDNA编码

第(3)题

答案：

COX2作为电子传递链复合体Ⅳ的亚基，参与电子传递，建立质子梯度，为ATP合成提供能量（质子动力势）。

MOTS-k与线粒体内膜上的转运蛋白MTM结合，MTM负责将丙酮酸转运进入线粒体基质，为柠檬酸循环提供底物，从而保证有氧呼吸的持续进行和ATP的持续合成。

两者分别从"能量供应"和"底物供应"两个维度协同配合，共同维持ATP的正常合成。
