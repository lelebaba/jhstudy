题目 17. [2023·丰台二模]

研究表明，电子设备中的蓝光会对线粒体造成损伤，影响有氧呼吸过程，对机体产生一定的伤害。

拿到这种题，三步走：

  2. 再看表格数据 — 哪些指标变了？哪些没变？变化规律是什么？

👉 去看正确答案

✅ 正确答案

(1) 答案

I、III、IV（或呼吸链复合物1、3、4）；线粒体基质；H+浓度梯度（或质子浓度梯度）

(2) 答案

蓝光照射导致线粒体含量减少，且呼吸链复合物1、2含量减少（尤其复合物2明显减少），使得电子传递链受阻，NADH脱下的电子传递效率下降，H+泵出量减少，H+浓度梯度降低，最终导致ATP合成减少。

(3) 答案

实验结果表明：随着暗培养时间的延长，果蝇在蓝光条件下的相对存活率升高。

第5组果蝇的培养条件是：一直进行暗培养（或60天暗培养，不转入蓝光条件）。

(4) 答案

蓝光导致线粒体受损，有氧呼吸产生的ATP减少，能量供应不足，导致脑神经细胞凋亡或损伤，进而形成空泡，最终引起脑神经退化。

👉 去看详细解析

🔍 详细解析

(1) 解析 识图填空

这道空考的是有氧呼吸第三阶段（电子传递链）的基础知识。图甲是线粒体内膜的结构示意图：

  • I、III、IV（复合物1、3、4）是质子泵，它们把H+从线粒体基质泵到膜间隙
  • 复合物II（复合物2）不是质子泵，它只负责传递电子，不泵H+
  • 泵出去的H+在膜间隙积累，形成H+浓度梯度（好比在蓄水池上方蓄水）
  • H+通过ATP合成酶回流时，驱动ATP合成（好比水流冲击水轮机发电）

易错点： 很多同学会写成"I、II、III、IV"全部转运H+，但根据图甲，II（复合物2）不泵H+，它只负责传递电子。这在后面的表格数据中也有体现——复合物2明显减少时，ATP也减少，说明它虽然不泵H+，但它的减少也会影响电子传递效率。

(2) 解析 因果分析

这一问的答题思路：从表格数据出发，沿着"蓝光→线粒体/复合物→电子传递→H+梯度→ATP"这条因果链推理。

第一步：看表格找变化

  • ATP含量 ↓ → 这是我们要解释的结果
  • 线粒体含量 ↓ → 发电厂本身变少了
  • 复合物1 ↓、复合物2 ↓↓ → 电子传递链的"传送带"部件坏了
  • 复合物3、4 无明显变化 → 不是所有部件都坏了

第二步：串联因果关系

蓝光 → 线粒体减少 + 复合物1、2减少 → 电子传递效率下降 → 泵出的H+减少 → H+浓度梯度降低 → 通过ATP合成酶的H+减少 → ATP合成减少

答题模板： 从现象到本质，层层递进，把每一步的因果关系写清楚。

(3) 解析 实验分析

这一问考的是实验设计中的对照组思维。

第一空（实验结果）： 看柱状图，1~4组暗培养时间依次增加（2天→20天→40天→60天），存活率依次升高。这说明"暗培养时间越长，果蝇抵抗蓝光的能力越强"。

第二空（第5组条件）： 这是一个关键考点！前面4组都经历了"暗培养→蓝光"，那第5组应该是什么？

科学实验需要对照组。前面4组都照了蓝光，那第5组应该是完全不照蓝光的对照组，用来证明"蓝光确实导致了存活率下降"。

所以第5组的条件是：一直暗培养（60天暗培养，不转入蓝光）。

注意： 如果第5组也是"60天暗培养后转入蓝光"，那它和前面4组就重复了，没有任何对照意义。

(4) 解析 综合推理

这道题的最后一步，把前面所有的线索串起来：

  • 线索①：蓝光 → 线粒体受损 → ATP减少（第1~2问结论）
  • 线索②：蓝光 → 脑神经组织出现空泡（图丙）
  • 推理：ATP是细胞的能量来源，脑神经细胞对能量需求特别大（大脑耗能占全身20%以上）。ATP供应不足 → 神经细胞无法维持正常功能 → 细胞凋亡/损伤 → 形成空泡 → 脑神经退化

答题要点： 一定要把"蓝光→线粒体→ATP→神经细胞→空泡→退化"这条因果链完整写出来，不能跳步。

🧪 ATP — 细胞的能量货币

ATP（当前） → 有氧呼吸 → 电子传递链 → 线粒体

💡 什么是ATP？一个比喻

想象你是一个外卖骑手，你的电动车需要电才能跑。电动车电池里的电，就相当于细胞的ATP。

  • ATP = 满电的充电宝 — 随时可以给细胞的各种活动供电
  • ADP + Pi = 没电的充电宝 — 需要充电才能再用
  • ATP → ADP + Pi（放能）— 放电，提供能量给肌肉收缩、神经传导等
  • ADP + Pi → ATP（需能）— 充电，需要线粒体有氧呼吸提供能量

🗣 ATP的结构

ATP全称是"三磷酸腺苷"，听起来复杂，但结构很简单：

  • A = 腺苷（一个"头"）
  • T = 三（三个磷酸基团）
  • P = 磷酸基团（三个"尾巴"连在一起）

关键知识点：ATP分子中，最末端的那个磷酸键是高能磷酸键，断裂时释放大量能量（约30.54 kJ/mol），这就是细胞能直接利用的"能量包"。

就像你钱包里的100元钞票——携带方便，随时能花。ATP就是细胞的"100元钞票"。

🔄 ATP的循环利用

人体每天消耗的ATP量非常惊人——大约相当于你自身的体重！但人体内ATP总量很少，只能维持几秒钟。所以关键在于：

ATP ↔ ADP + Pi（不断循环）

合成ATP的途径：

  • ✅ 有氧呼吸（主要途径，产生大量ATP）
  • ✅ 无氧呼吸（次要途径，产生少量ATP）
  • ✅ 光合作用（植物专属）

这道题中的蓝光破坏了线粒体，导致有氧呼吸受阻，ATP合成减少，细胞就"断电"了。

⚡ 有氧呼吸 — 细胞的发电厂

ATP → 有氧呼吸（当前） → 电子传递链 → 线粒体

🏛 有氧呼吸的总览

有氧呼吸就是细胞"燃烧"葡萄糖来产生ATP的过程。就像火力发电厂烧煤发电一样：

C6H12O6 + 6O2 → 6CO2 + 6H2O + 能量（约30~32个ATP）

整个有氧呼吸分三个阶段，分别在细胞的不同位置进行：

📊 三个阶段，一张表看懂

阶段场所原料产物产生ATP
第一阶段（糖酵解）细胞质基质葡萄糖丙酮酸 + [H]（NADH）少量（2个ATP）
第二阶段（三羧酸循环）线粒体基质丙酮酸CO2 + [H]（NADH/FADH2）少量（2个ATP）
第三阶段（电子传递链）线粒体内膜[H] + O2H2O大量（约26~28个ATP）

关键点： 第三阶段产生的ATP最多，占整个有氧呼吸的85%以上。这道题考的就是第三阶段——电子传递链。

🎯 三个阶段的比喻

想象你开了一家馒头店：

  • 第一阶段（糖酵解）： 你先把面粉（葡萄糖）粗略揉成面团（丙酮酸），这个过程在厨房（细胞质基质）里进行，只赚了2块钱（2个ATP）
  • 第二阶段（三羧酸循环）： 你把面团搬到专门的发酵室（线粒体基质），加入酵母，进行精细发酵，又赚了2块钱（2个ATP），还产生了大量"蒸汽"（[H]）
  • 第三阶段（电子传递链）： 你把蒸汽引导到蒸汽轮机（线粒体内膜），推动轮机发电，赚了大钱——26~28块钱（26~28个ATP）！

所以第三阶段最关键，赚的钱最多！而蓝光恰好破坏了第三阶段，所以ATP就严重不足了。

⚡ 电子传递链 — 能量传送带

ATP → 有氧呼吸 → 电子传递链（当前） → 线粒体

🔥 什么是电子传递链？

电子传递链是有氧呼吸第三阶段的核心内容，它位于线粒体内膜上。这道题的图甲画的就是这个。

一个比喻： 想象一条流水线传送带，上面有4个工人（复合物1~4）。工人A把货物（电子）传给工人B，B传给C，C传给D，最后把货物交给O2（氧气）。

但这条传送带不是普通的传送带——每一次传递，都会释放出能量，这些能量被用来"泵水"（泵H+），把水从低处抽到高处，形成一个水位差。

🏙 线粒体内膜上的"水电站"

让我们用"水电站"的比喻来理解：

  • 线粒体基质 = 下游的河床（低水位，H+少）
  • 膜间隙 = 上游的水库（高水位，H+多）
  • 复合物I、III、IV = 三台水泵，把水从下游抽到上游（消耗能量）
  • 复合物II = 只是传送带上的一个齿轮，不负责泵水
  • ATP合成酶 = 水轮机，水从高处流下来时，推动它旋转发电（合成ATP）

电子（来自NADH）沿着复合物传递时释放能量 → 能量驱动水泵（复合物I、III、IV）把H+泵到膜间隙 → 形成H+浓度梯度（水位差） → H+通过ATP合成酶回流 → 驱动ATP合成

💰 线粒体 — 细胞的充电宝工厂

ATP → 有氧呼吸 → 电子传递链 → 线粒体（当前）

🌐 线粒体是什么？

线粒体是细胞内的一个"细胞器"（可以理解为细胞里的一个小器官），它的主要功能是进行有氧呼吸，产生ATP。

比喻： 线粒体就像你手机里的充电宝工厂。它把"燃料"（葡萄糖、脂肪酸）通过有氧呼吸"燃烧"，然后把产生的能量储存在ATP这个"充电宝"里，供细胞随时使用。

👁 线粒体的结构

线粒体有双层膜结构：

  • 外膜 — 最外面的一层，相当于工厂的外墙
  • 内膜 — 里面的一层，向内折叠形成嵴（像折扇一样折叠，增加表面积），电子传递链就嵌在内膜上
  • 膜间隙 — 外膜和内膜之间的空间
  • 基质 — 内膜内部的空间，有氧呼吸第二阶段在这里进行

关键点：线粒体内膜折叠成嵴，是为了增加表面积，让更多的电子传递链复合物和ATP合成酶镶嵌在上面，这样就能产生更多ATP。

🔬 题目中的实验设计

这道题第(3)问考的是实验设计中最核心的概念——对照组。

一个故事： 小明想测试"熬夜会不会影响考试成绩"。他找了几个同学，让他们连续熬夜3天，然后考试。结果发现这些同学成绩都不好。小明得出结论：熬夜导致成绩下降。

问题出在哪里？

  • 小明没有设置对照组——那些没有熬夜的同学成绩怎么样？
  • 如果没熬夜的同学成绩也不好，那就说明不是熬夜的问题，可能是题目太难了

📄 实验设计的三个基本要素

要素定义本题中的例子
自变量（你改变的东西）实验者主动改变的因素是否用蓝光照射、暗培养时间长短
因变量（你观察的结果）随自变量变化而变化的指标ATP含量、存活率、脑组织空泡
控制变量（保持不变的）其他可能影响结果的因素，必须保持一致果蝇品种、日龄、温度、食物等

💡 为什么第5组是"一直暗培养"？

再看题目中的实验设计：

  • 1组：暗培养2天 → 蓝光
  • 2组：暗培养20天 → 蓝光
  • 3组：暗培养40天 → 蓝光
  • 4组：暗培养60天 → 蓝光
  • 5组：暗培养60天 → 继续暗培养（不照蓝光）

第5组的作用是：作为对照，证明"蓝光"确实降低了存活率。

如果第5组存活率明显高于第4组，就说明蓝光确实有害。如果第5组和第4组存活率差不多，那就说明蓝光没什么影响，存活率低是其他原因（比如果蝇太老了）。

这就是为什么第5组不能照蓝光——它要提供一个"没有蓝光"的参考基准。
