物理7：变压器供电·开关断开时的动态分析（选择题）

📝 原题概述

变压器给用户供电的示意图。输入电压恒定（市区电网电压），两条输电线总电阻为 R₁，电阻 R₂ 和 R₃ 代表用户用电器（定值电阻），电表均为理想交流电表。开关 S 由闭合切换为断开，判断哪个说法正确。

🔑 解题关键：理清电路结构

R₂ 和 R₃ 是并联关系，S 控制的是 R₃ 所在的支路。

  • S 闭合：负载 = R₂ ∥ R₃（两个用电器并联，总电阻较小）
  • S 断开：负载 = R₂（只用一个用电器，总电阻增大）

变压器输入电压恒定 → 副线圈输出电压 U₂ 恒定（理想变压器）。

📖 不清楚变压器为什么"输入恒定→输出恒定"？看 变压器原理详解

🔄 逐项分析

第一步：判断总电阻变化

S 断开 → R₃ 支路断开 → 负载从 R₂∥R₃ 变为只有 R₂ → R 并联增大。

R并联 = R₂∥R₃ < R₂ → 断开后 R并联 = R₂（增大）

第二步：判断电流变化

I₂ = U₂ / (R₁ + R并联) → R并联↑ → I₂↓（减小）
副线圈电流减小

原线圈电流也减小：I₁ = I₂ × (n₂/n₁) → I₁↓

第三步：判断电压变化

UR₁ = I₂ × R₁ → I₂↓ → UR₁↓（减小）
U负载 = U₂ − UR₁ → UR₁↓ → U负载↑（增大）

V₂ 测的是负载电压 → V₂ 增大。

第四步：判断功率变化

P总 = U₂ × I₂ → I₂↓ → P总↓（减小）
PR₁ = I₂² × R₁ → I₂↓ → PR₁↓（减小）
选项内容分析结论
AV₂ 示数不变V₂ 测负载电压，负载电压增大❌
BA 示数增大A 测原线圈电流，电流减小❌
C总功率增大P = U₂I₂，I₂ 减小 → P 减小❌
DR₁ 的功率减小P = I₂²R₁，I₂ 减小 → P 减小✅

✅ 答案：D

开关 S 断开后，R₃ 支路断开，负载总电阻增大，副线圈电流减小，R₁ 上的功率 P = I₂²R₁ 随之减小。

💡 解题口诀："断负载 → 电阻增 → 电流降 → 线损降、负载电压升"。这一类型的动态分析题，核心是抓住 "谁恒定、谁变化"，然后沿着 U→I→P 的链条逐步推导。

物理18：远距离输电（计算题）

📝 原题概述

发电站通过远距离输电给工厂供电。升压变压器 T₁ 匝数比 n₁:n₂ = 1:100，输电线等效电阻 R = 100Ω，降压变压器 T₂ 匝数比 n₃:n₄ = 200:1，变压器均为理想变压器。工厂输入电压 U₄ = 220V，用电功率 P = 440kW。

📖 远距离输电的完整模型分析参见：远距离输电详解

第(1)问：工厂干路电流 I₃

工厂消耗的功率和电压已知，直接用 P = UI 求电流。

I₃ = P / U₄ = 440 000 W / 220 V = 2000 A

✅ 答案：I₃ = 2000 A

这一步最简单，工厂侧的功率和电压已知，电流 = 功率 ÷ 电压。

第(2)问：输电线损耗功率 P损

关键：输电线上的电流不是 I₃，而是 I₂（输电线中的电流）。需要通过变压器变流关系求出 I₂。

步骤1：求 T₂ 原线圈电压 U₃

U₃ / U₄ = n₃ / n₄ = 200 / 1 = 200
U₃ = U₄ × 200 = 220 × 200 = 44 000 V

步骤2：求输电线电流 I₂

I₂ / I₃ = n₄ / n₃ = 1 / 200
I₂ = I₃ / 200 = 2000 / 200 = 10 A

💡 理解：T₂ 是降压变压器，电压降 200 倍，电流就升 200 倍。工厂侧 2000A 的大电流，到输电线侧变成了 10A 的小电流——这就是"升压输电减少线损"的原理。

步骤3：求线损功率

P损 = I₂² × R = 10² × 100 = 10 000 W = 10 kW

✅ 答案：P损 = 10 kW

工厂消耗 440kW，线路损耗仅 10kW，效率 = 440/(440+10) ≈ 97.8%。高压输电的优越性体现在这里。

📖 为什么线损用 I²R 而不是 UI？为什么升压能减小线损？看 远距离输电详解

第(3)问：功率提升后发电站输出电压 U₁

工厂功率提升到 P' = 880kW，U₄ 保持 220V 不变，求新的 U₁。

步骤1：求新的工厂电流

I₃' = P' / U₄ = 880 000 / 220 = 4000 A

步骤2：求新的输电线电流

I₂' = I₃' / 200 = 4000 / 200 = 20 A

步骤3：求新的线路压降

ΔU' = I₂' × R = 20 × 100 = 2000 V

注意：U₃ 不变！因为 U₄ 固定、T₂ 匝数比固定 → U₃ = 44 000V 始终不变。

步骤4：求 T₁ 副线圈电压（送电端）

U₂' = U₃ + ΔU' = 44 000 + 2 000 = 46 000 V

💡 关键点：送电端电压 = 受电端电压 + 线路压降。电流增大了，线路压降增大了，送电端必须提高电压来补偿。

步骤5：求发电站输出电压

U₁' = U₂' / (n₂/n₁) = 46 000 / 100 = 460 V

✅ 答案：U₁ = 460 V

原状态 U₁ = 450V，功率翻倍后需要 460V。提高的 10V 用来补偿增加的线路压降。

💡 验算：新状态下线损 = I₂'² × R = 20² × 100 = 40kW，是原来的 4 倍（电流翻倍 → 线损 ×4）。这就是为什么电力系统要尽量用更高的输电电压。
