🔧 电路基础

串并联、欧姆定律、功率——理解变压器电路的最底层工具

首页 › 远距离输电 › 电路基础

📏 欧姆定律

I = U / R  |  U = I × R  |  R = U / I 电流 = 电压 ÷ 电阻

这是电路分析的基石。在本题中：

  • 物理7：I₂ = U₂ / (R₁ + R负载) —— 副线圈回路的总电流
  • 物理18：I₂ = P / U₂ —— 输电线电流（用功率和电压求）
  • 物理18：ΔU = I₂ × R —— 输电线上的压降

🔗 串联电路

在物理7和物理18中，副线圈回路都是串联结构：变压器输出 → 输电线电阻 R₁ → 负载。

串联三原则

① 电流处处相等：I₁ = I₂ = I₃ = ...
② 电压相加：U_总 = U₁ + U₂ + ...
③ 电阻相加：R_总 = R₁ + R₂ + ...

在物理7中：U₂（副线圈电压）= U_R₁ + U_负载。当 I₂ 减小时，U_R₁ = I₂×R₁ 减小，所以 U_负载 = U₂ − U_R₁ 增大。这就是为什么"负载电压变大"。

在物理18中：U₂（送电端）= U₃（受电端）+ ΔU（线路压降）。当 I₂ 增大时，ΔU 增大，需要提高 U₂ 来保持 U₃ 不变。这就是第(3)问的核心逻辑。

🔀 并联电路

在物理7中，R₂ 和 R₃ 是并联的——两个用电器同时接在电路中。

并联三原则

① 电压处处相等：U₁ = U₂ = U₃ = ...
② 电流相加：I_总 = I₁ + I₂ + ...
③ 电阻倒数相加：1/R_总 = 1/R₁ + 1/R₂ + ...

关键结论：并联电阻的总电阻小于任何一个支路电阻。

当 S 断开时，R₃ 支路断开，总电阻从 R₂∥R₃ 变为 R₂ → 总电阻增大。这就是物理7动态分析的起点。

💡 比喻：并联像"多开了一条路"。两条路并排走，总流量（电流）更大，整体"阻力"更小。关掉一条路，总流量减小，整体"阻力"增大。

⚡ 电功率

电路中的功率有三种表达方式：

P = U × I  |  P = I² × R  |  P = U² / R
公式适用场景在题目中用于
P = UI已知电压和电流求工厂功率 P = U₄×I₃
P = I²R已知电流和电阻求线损 P损 = I₂²×R
P = U²/R已知电压和电阻求负载功率

物理7中的功率分析：

  • P_总 = U₂ × I₂ → I₂↓ → P_总↓（选项C的判断依据）
  • P_R₁ = I₂² × R₁ → I₂↓ → P_R₁↓（选项D的判断依据）✅
  • 注意：P = I²R 和 P = U²/R 不能混用！R₁ 的功率用 I²R（因为电流已知），负载功率用 U²/R（因为电压已知）

物理18中的功率分析：

  • P_损 = I₂² × R = 10² × 100 = 10kW（第2问）
  • P_总 = P_用 + P_损 = 440 + 10 = 450kW（验证）
  • 功率翻倍后：I₂ 翻倍 → P_损 变为 4 倍（I² 的平方效应）

📝 为什么线损用 P = I²R 而不是 P = UI？

这是很多同学容易混淆的点：

  • P = UI：U 是该元件两端的电压。对于输电线，U_R₁ = I₂×R₁（线路压降），所以 P_R₁ = I₂ × (I₂×R₁) = I₂²×R₁ ✓
  • 如果用输电电压 U₂ 来算：P = U₂×I₂ 算的是总输电功率，不是线损！

本质原因：线损是电流流过电阻R₁时"浪费"的能量，它只取决于电流和线路电阻，与输电电压无关。这就是为什么升压能减少线损——升压→电流减小→I²R减小。
