💡 交流电基础

变压器依赖交流电工作——先搞懂什么是交流电

首页 › 动态分析 › 交流电基础

🔄 什么是交流电？

直流电（DC）：电流方向不变，像水管里一直朝一个方向流的水。电池就是直流电源。

交流电（AC）：电流方向周期性变化，像钟摆一样来回摆。家用插座就是交流电源（频率50Hz，方向每秒改变100次）。

⚙️ 交流电的产生

交流电是通过发电机产生的。原理：线圈在磁场中匀速旋转 → 穿过线圈的磁通量周期性变化 → 产生周期性变化的感应电动势。

这本质就是电磁感应的应用——法拉第电磁感应定律的直接体现。📖 详见 电磁感应

e = Em × sin(ωt)
瞬时电动势 = 峰值 × sin(角频率 × 时间)
  • Em：电动势峰值（最大值）
  • ω：角频率，ω = 2πf（f 是频率，中国电网 f = 50Hz）
  • T：周期，T = 1/f = 0.02s

📐 有效值与峰值

交流电的电压/电流是不断变化的，那题目中的"220V"是指什么？——有效值。

有效值的定义：让交流电和直流电通过同样的电阻，如果它们在相同时间内产生的热量相等，就把这个直流电的值称为交流电的有效值。

U有效 = Um / √2   I有效 = Im / √2 有效值 = 峰值 ÷ √2 ≈ 峰值 × 0.707
峰值有效值关系
家用电压311V220V311 = 220 × √2
题目中 U₄ = 220V—220V有效值

💡 重要约定：题目中给定的电压、电流数值（如 220V、2000A）都是有效值，除非特别说明。交流电表的读数也是有效值。计算功率 P = UI 用的也是有效值。

🔗 交流电与变压器的关系

回到本题，两道题都涉及变压器，而变压器只对交流电有效：

  • 物理7：市区电网 → 交流电 → 变压器工作 → 改变电压给用户
  • 物理18：发电站产生交流电 → 升压变压器 → 远距离输电 → 降压变压器 → 工厂使用

变压器改变电压的本质是电磁感应（互感），而电磁感应要求磁通量必须变化——只有交流电才能让磁通量不断变化。
