🏗️ 远距离输电的标准模型

远距离输电系统由五段组成，每段有不同的电压、电流和功率：

📐 五段模型的关键关系

段电压电流功率
①发电U₁I₁P₁ = U₁I₁
②T₁升压后U₂ = U₁×(n₂/n₁)I₂ = I₁×(n₁/n₂)P₂ = P₁（理想）
③输电线U₂ → U₃（有压降）I₂（不变）P₂ = P₃ + P损
④T₂降压后U₄ = U₃×(n₄/n₃)I₃ = I₂×(n₃/n₄)P₄ = P₃（理想）
⑤用户U₄I₃P₄ = U₄I₃

三个核心等式

① 功率守恒：P₁ = P₂ = P₃ + P损 = P₃ = P₄
② 电压关系：U₂ = U₃ + I₂×R（输电线上有压降）
③ 线损：P损 = I₂² × R = ΔU × I₂ = (U₂ − U₃) × I₂

💡 为什么要升压输电？

这是远距离输电的核心问题，也是物理18的设计思想。

问题：输送功率 P 不变，输电线电阻 R 不变。怎么减少线损？

P损 = I₂² × R   其中 I₂ = P / U₂
→ P损 = (P/U₂)² × R = P² × R / U₂²

功率 P 和电阻 R 都不变，线损与 U₂ 的平方成反比！

输电电压 U₂输电线电流 I₂线损 P损 = I₂²R效率

💡 一句话："电压升高 N 倍，线损减小 N² 倍"。这就是为什么电力系统不断追求更高的输电电压——从 10kV → 110kV → 220kV → 500kV → 特高压 1000kV。

🧩 物理18解题流程图

把物理18的解题过程整理成标准流程，以后遇到类似题目照着走：

  1. 从用户端出发：已知 U₄ 和 P → I₃ = P/U₄
  2. 过 T₂ 降压变压器：U₃ = U₄×(n₃/n₄)，I₂ = I₃×(n₄/n₃)
  3. 算输电线压降和线损：ΔU = I₂×R，P损 = I₂²×R
  4. 算送电端电压：U₂ = U₃ + ΔU
  5. 过 T₁ 升压变压器：U₁ = U₂×(n₁/n₂)

总结：从用户端出发，经过"降压变压器→输电线→升压变压器"一路反推回发电站。每一环节用变压器三大关系（电压比、电流比、功率守恒）。
