📋 改编题一：选择题（动态分析）

如图，理想变压器原线圈接电压恒定的交流电源，副线圈回路中 R₁ 为输电线总电阻，R₂ 和 R₃ 为用户用电器（定值电阻），S 为开关。现将滑动变阻器 R₃ 的滑片向上移动（R₃ 阻值增大），下列说法正确的是：

A. 电压表 V₁ 示数增大
B. 电流表 A 示数增大
C. R₁ 上消耗的功率增大
D. R₂ 上消耗的功率减小

💡 解析

✅ 答案：D

因果链推导：

  1. R₃ 阻值增大 → R₂∥R₃ 的并联总电阻增大
  2. R总 = R₁ + R₂∥R₃ → R总增大
  3. I₂ = U₂ / R总 → I₂减小
  4. I₁ = I₂ × (n₂/n₁) → I₁减小 → A示数减小 → B错
  5. U_R₁ = I₂×R₁ → U_R₁减小 → U负载 = U₂ − U_R₁增大
  6. V₁ 测负载电压 → V₁增大... 等等！

注意区分：V₁ 如果测负载两端电压，则 V₁ 增大（A错）。但如果 V₁ 测的是副线圈输出电压 U₂，则不变。这里假设 V₁ 测负载电压。

R₂ 上的功率：P_R₂ = U_负载² / R₂ → U_负载增大 → P_R₂ 增大... 等等再想一下！

实际上 R₂ 和 R₃ 并联，R₂ 两端电压 = U_负载。U_负载增大 → P_R₂ = U²/R₂ 增大。所以 D 说"R₂ 功率减小"是错误的。

重新审视各选项：R₁ 功率 P = I₂²R₁ → I₂ 减小 → P_R₁ 减小 → C 错。

如果 V₁ 测 U₂（副线圈输出），则不变 → A 错。如果测 U_负载，则增大 → A 错。

正确答案取决于 V₁ 测什么。 假设 V₁ 测负载电压，则四项都可能错。让我们修正题目为"R₂ 上消耗的功率增大"作为正确选项。

修正后正确答案：D 不正确。正确答案应为 "R₂ 消耗的功率增大"（因为负载电压增大，R₂ 不变，P = U²/R 增大）。

本题意在练习因果链推导。R₃ 增大 → 电流减小 → 线损减小 → 负载电压增大 → 负载功率（R₂ 上）增大。

📋 改编题二：计算题（远距离输电）

某小型水电站用 1000V 电压直接向远处的村庄输电（不经过变压器），输电线总电阻 R = 5Ω，村庄需要功率 P = 50kW，电压 U = 200V。

(1) 如果不加变压器直接输电，输电线上的电流为多少？线损为多少？
(2) 如果改为升压输电（T₁ 匝数比 1:5，T₂ 匝数比 5:1），村庄端电压仍保持 200V，线损变为多少？
(3) 比较两种方案的输电效率。

✅ 答案

第(1)问：直接输电

输电线电流 I = P / U = 50 000 / 200 = 250 A

线损 P损 = I²R = 250² × 5 = 312 500 W = 312.5 kW

这比村庄需要的功率还大！输电效率 = 50 / (50 + 312.5) ≈ 13.8%

第(2)问：升压输电

T₁ 升压：U₂ = 1000 × 5 = 5000V

T₂ 降压：U₃ = 200 × 5 = 1000V（T₂ 原线圈端电压）

村庄电流 I₃ = 50 000 / 200 = 250 A

输电线电流 I₂ = I₃ × (n₄/n₃) = 250 × (1/5) = 50 A

线损 P损 = I₂²R = 50² × 5 = 12 500 W = 12.5 kW

第(3)问：效率比较

方案输电电压输电线电流线损效率
直接输电200V250A312.5kW13.8%
升压输电5000V50A12.5kW80%

升压 25 倍（200V → 5000V），电流降为 1/5，线损降为 1/25（I²效应：1/5² = 1/25）。

结论：没有变压器的直接输电几乎不可行——87% 的能量损耗在输电线上！升压变压器是远距离输电的必需品。

📋 改编题三：概念辨析

判断以下说法是否正确，点击查看答案：

说法1：变压器可以改变直流电的电压

❌ 错误

变压器利用互感原理工作，需要磁通量变化。直流电电流恒定，磁通量不变化，副线圈不会产生感应电动势。变压器只能用于交流电。

说法2：理想变压器的输入功率等于输出功率

✅ 正确

理想变压器无能量损耗（无铜损、无铁损、无漏磁），P₁ = P₂ 即 U₁I₁ = U₂I₂。这是理想变压器三大关系之一。

说法3：输电电压提高为原来的 N 倍，线损减小为原来的 N 倍

❌ 错误

线损 P损 = I²R = (P/U)²R = P²R/U²。电压提高 N 倍，线损减小为原来的 1/N²（平方反比），不是 1/N。例如电压提高 10 倍，线损减小为 1/100。

说法4：并联负载越多，总电阻越大

❌ 错误

并联越多，总电阻越小。1/R总 = 1/R₁ + 1/R₂ + ...，支路越多，1/R总 越大，R总 越小。这就是"多开一条路，总阻力更小"的道理。

说法5：变压器原线圈电流由副线圈电流决定

✅ 正确

理想变压器中，副线圈电流由负载决定（I₂ = U₂/R负载），原线圈电流由电流比关系决定（I₁ = I₂ × n₂/n₁）。所以"副线圈决定原线圈"——负载变了，副线圈电流变，原线圈电流跟着变。这就是动态分析的因果链起点。

🎯 知识总结清单

  • 变压器三大关系：电压比=匝数比、电流比=匝数反比、功率守恒
  • 变压器只能用交流电（电磁感应要求磁通量变化）
  • 动态分析因果链：负载电阻变→电流变→线损变→负载电压变
  • 线损公式：P损 = I²R（用电流算，不用输电电压算）
  • 升压减损原理：P不变时，U↑→I↓→I²R↓，线损与U²成反比
  • 送电端电压 = 受电端电压 + 线路压降（串联分压）
  • 有效值 = 峰值/√2，题目中的电压电流均为有效值
  • 远距离输电五段模型：发电→升压→输电→降压→用户
