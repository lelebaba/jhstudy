📊 变压器动态分析技巧

负载变化时，各物理量怎么变？——掌握"因果链"就一通百通

首页 › 题目分析 › 动态分析技巧

🎯 核心问题：负载变了，各量怎么变？

物理7考查的就是这类问题：开关 S 闭合/断开 → 负载变化 → 各物理量（电压、电流、功率）怎么变？

这类题的解法不需要死记公式，只需要沿着因果链条逐步推导。

📐 第一步：确定"恒定量"

解题前先明确哪些量不变，这些是推导的出发点。

恒定量原因在物理7中
输入电压 U₁接在市区电网上，波动忽略U₁ 不变 ✓
输出电压 U₂理想变压器 U₂ = U₁×(n₂/n₁)，匝数比不变U₂ 不变 ✓
匝数比 n₁:n₂变压器结构固定不变 ✓
输电线电阻 R₁物理结构固定不变 ✓

💡 关键：U₂ 恒定是整个推导的起点。如果题目说"输入电压恒定"，那 U₂ 就恒定；如果题目说"输出电压恒定"，那 U₂ 也是恒定的（但要注意此时 U₁ 可能需要变化）。

🔄 第二步：从负载变化出发的因果链

负载变化（如开关断开/闭合、电阻增大/减小）是变化的源头，之后的一切变化都从这里开始推导。

一句话总结：负载电阻↑ → 电流↓ → 线损(U_R₁, P_R₁)↓ → 负载电压↑

📋 常见场景速查表

场景R负载I₂U_R₁U负载P_R₁P总
开关断开（并联负载减少）↑↓↓↑↓↓
开关闭合（并联负载增加）↓↑↑↓↑↑
负载电阻增大↑↓↓↑↓↓
负载电阻减小↓↑↑↓↑↑

💡 记忆口诀："负载增→电流降→线损降→负载电压升"。只需记住电流是中间量——负载电阻决定电流大小，电流决定其他一切。

⚠️ 易错点提醒

易错1：误认为副线圈电压 U₂ 会随负载变化

错误："负载增大 → 电流增大 → 副线圈电压增大"

正确：U₂ 只由 U₁ 和匝数比决定，与负载无关。负载变化改变的是电流，不是 U₂ 本身。

易错2：误认为功率与电流成正比

错误："电流减半 → R₁ 的功率也减半"

正确：P = I²R，功率与电流的平方成正比。电流减半 → 功率变为 1/4。

易错3：混淆"负载电压"和"副线圈电压"

当电路中有输电线电阻 R₁ 时：副线圈电压 U₂ ≠ 负载电压 U负载。正确关系是 U₂ = U_R₁ + U负载（串联分压）。

🧩 用因果链解题：物理7复盘

把物理7的推导用因果链走一遍：

  1. S 断开 → R₃ 支路断开 → R负载 从 R₂∥R₃ 变为 R₂ → R负载↑
  2. R负载↑ → I₂ = U₂/(R₁+R负载) → I₂↓
  3. I₂↓ → I₁ = I₂×(n₂/n₁) → I₁↓（A示数↓ → 选项B错）
  4. I₂↓ → U_R₁ = I₂×R₁ → U_R₁↓
  5. U_R₁↓ → U负载 = U₂ − U_R₁ → U负载↑（V₂↑ → 选项A错）
  6. I₂↓ → P总 = U₂×I₂ → P总↓（选项C错）
  7. I₂↓ → P_R₁ = I₂²×R₁ → P_R₁↓（选项D正确 ✅）

每一步都是机械推导，不需要额外假设。只要第一步对了（判断 R负载 怎么变），后面顺水推舟。
